# もざや｜画像モザイク・ぼかしツール

画像の好きな範囲にモザイクやぼかしをかけられる、ブラウザ完結型の静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

| 項目 | 内容 |
|---|---|
| バージョン | 1.0.0 |
| 状態 | 公開中 |
| 稼働先 | [mozaya.vercel.app](https://mozaya.vercel.app) |
| 実装 | 静的 Web サイト（素の HTML / CSS / JavaScript）＋ Windows 版（.NET 8 / WinForms） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## 📖 概要

**読み込んだ画像ファイルがブラウザの外に出ることは一切ありません。**サーバーへのアップロードは行わず、すべての処理はお使いの端末のブラウザ内だけで完結します。

## ✨ 機能

- PNG / JPG 画像の読み込み（ファイル選択とドラッグ＆ドロップの両対応）
  - 対応していないファイルを選んだ場合は日本語でエラーを表示します
- 画像の上でドラッグして四角い範囲を追加し、モザイク（ピクセル化）またはぼかしを適用
  - 加工の種類は範囲を追加する前に切り替えます。各範囲には追加時点の種類と強さが記録されます
  - 強さスライダー（4〜40）：モザイクはブロックの大きさ、ぼかしはぼけ具合に効きます
- 加工範囲の一覧表示（種類・強さ・座標つき）、範囲ごとの個別削除
- 「最後の範囲を取り消す」（元に戻す）と「範囲をすべて消す」
- PNG 形式でダウンロード（もとの画像と同じ解像度で書き出し、範囲の枠線は含まれません）
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- テーマ切り替え（ダーク既定＋ライト、手動トグルで保存されます）

## 📝 使い方

1. 画像エリアをクリックしてファイルを選ぶか、画像をドラッグ＆ドロップして読み込みます。
2. 加工の種類（モザイク／ぼかし）と強さを選んでから、画像の上でドラッグして範囲を指定します。ドラッグを離すと加工がかかります。
3. 間違えた範囲は一覧から個別に削除するか、「最後の範囲を取り消す」で戻せます。
4. 「PNGでダウンロード」を押すと、加工結果が元の解像度で保存されます（ファイル名は「元の名前-mozaya.png」）。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。PNG / JPG 画像の読み込み（ファイル選択とドラッグ＆ドロップの両対応）、ドラッグでの範囲追加、範囲ごとの種類・強さの保持、一覧からの個別削除・取り消し・全消しに対応し、元の解像度で PNG または JPEG で保存できます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Mozaya.exe` を生成（Release にはバイナリを添付しない方針のため、配布物は各自ビルド）
- ロジックテスト: `windows/tests/run-tests.sh`（純粋ロジックのみを対象にし、Windows でなくても実行できます）
- ぼかしは縮小＋簡易ボックスブラー＋高品質拡大で実装しています（Web 版の Canvas フィルターとは計算方法が異なるため、見た目がわずかに違う場合があります）

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 純粋ロジック（パラメータ換算・矩形計算・座標変換）は `js/mozaya-core.js` に分離し、`tests/` の単体テスト（25件）で仕様を固定しています。Windows 版の純粋ロジックは `windows/MozayaLogic.cs` で、同じ仕様を `windows/tests/`（35件）で固定しています。
- もとの画像は元の解像度のままオフスクリーンの Canvas に保持し、表示用 Canvas も同じ解像度で、CSS で画面幅に合わせて縮小表示します。ドラッグ座標は表示倍率から元画像座標へ換算します。
- 描画は毎回もとの画像から全範囲を描き直す方式なので、加工が重ねがけで劣化することはありません。
- モザイクは範囲を小さく縮小してから拡大（スムージング無効）して描画、ぼかしは範囲でクリップしたうえで `ctx.filter` の blur をかけて描画します（隣接ピクセルを使った自然なぼかしになります）。
- 保存する状態はテーマ（localStorage キー `mozaya-theme`）のみです。画像や加工範囲は保存しません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: mozaya-v1）。

設計判断とパリティ棚卸しの詳細は [DESIGN.md](DESIGN.md) に記録しています。既知の注意点（画像端のぼかし透け）への対応方針もそちらにあります（一時対処として画面に赤字の注意事項を明記済み、恒久対応は検討送り・未決定）。

## ⚠️ 注意

画像の端付近や小さい画像に強いぼかしをかけると、ぼかした部分からもとの画像がうっすら透けて見える場合があります。

- 原因：ぼかしフィルタは元画像の外周で不透明度を落とす性質があり、本ツールの描画方式（元画像の上にぼかした画像を範囲で切り抜いて重ねる）では、不透明度が落ちた部分から下の鮮明な元画像が見えます。最悪条件（60×60 全面・強さ40）では市松模様の隣接差分が 255→114 までしか下がりませんでした。通常サイズ・画像内側の範囲では問題ありません（残存差分 3.3〜0.00）。検証は @napi-rs/canvas（Skia 系）での測定で、実ブラウザでの最終確認は未実施です。
- 対処：画面の「2. 範囲を選んで加工する」に赤字の注意事項を明記し、端にある文字などを隠す場合はモザイクとの併用を案内しています。
